# A few examples on Liyh

A small list of examples is presented here to illustrate the language through both mundane and more specialised tasks. The purpose of these examples is to show as much as possible how Liyh can be used.

 - [AskProcedure](AskProcedure.ly) : A procedure is defined to ask the user to enter text of a certain type.
 - [CustomList](CustomList.ly) : We define the 'List' type via a sum type, and some procedures that go with it.
 - [ElectronicConfiguration](ElectronicConfiguration.ly) : A procedure is defined to generate the electronic configuration of an element given its atomic number.
 - [Factorial](Factorial.ly) : Several methods are defined for generating the factorial of a number.
 - [Factorial.lysm](Factorial.lysm) : Implementation of the factorial in IL of the Liyh VM.
 - [IsPrime](IsPrime.ly) : A method is defined that checks whether the given number is prime.
 - [LinearRegression](LinearRegression.ly) : A statistics library (in Liyh) is used to perform a linear regression on data from a file. The graph is shown.
 - [MaybeType](MaybeType.ly) : We define the 'Maybe' type with a sum type, and some procedures that go with it.
 - [PlusLessGame](PlusLessGame.ly) : We implement the game of more or less.
 - [ReferenceCell](ReferenceCell.ly) : We define the type of reference cell (as in F#). Note that this is not recommended in practice, but it illustrates useful concepts.
 - [RungeKutta](RungeKutta.ly) : RK4 is implemented for functions from R into R.
 - [SquareErrorRegression](SquareErrorRegression.ly) : A linear regression is performed on data that provide errors.
